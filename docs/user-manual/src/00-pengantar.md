# Pengantar

Panduan ini dibuat untuk pengguna aktif aplikasi surat kecamatan: staf data entry, Camat sebagai supervisor, administrator sistem, dan auditor pihak ketiga.

## Tentang Aplikasi

Aplikasi ini menggantikan sistem arsip surat fisik dengan platform digital yang punya 4 karakteristik utama:

1. **Operasional offline-friendly** — staf bisa bekerja saat internet kantor terputus, perubahan tersinkron otomatis saat kembali online.
2. **Audit trail lengkap** — setiap perubahan tercatat (siapa, kapan, apa) tanpa perlu konfigurasi tambahan.
3. **Supervisi camat** — disposisi mengalir ke staf, status terpantau dashboard, statistik dan laporan kerja.
4. **Educational** — instance demo kampus terhubung ke materi kuliah Struktur Data, Algoritma, Basis Data via "student mode".

## Cara Membaca Panduan

- **Tutorial step-by-step**: setiap fitur dijelaskan dengan urutan klik konkret + screenshot.
- **Tips & catatan**: blok kutip (`>`) berisi peringatan atau saran best practice.
- **Konsep di balik fitur**: kalau Anda ingin paham _kenapa_ fitur didesain demikian, panduan ini menyertakan rujukan ke catatan arsitektur dan keputusan desain.
